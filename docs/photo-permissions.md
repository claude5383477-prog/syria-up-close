# أذونات الصور

- **مجموعة `sv-*` في `src/content/photos.json`**: صور حساب Syria Visuals على X. صاحب الحساب سمح لصاحب المشروع باستخدامها كلها، وطلب ألا يُذكر اسمه أو رابط حسابه (26 تشرين الأول 2026). تظهر بعبارة "صورة من مجموعة سوريا عن قرب". مربوطة حالياً بروابط X؛ `npm run photos:localize` ينسخها إلى `public/guide`.
- **صور ويكيميديا كومنز**: تراخيص حرة، ويظهر اسم المصوّر والترخيص على كل صورة (`npm run photos:fill`).
